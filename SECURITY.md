# Security Policy

## Reporting Security Issues

The Athenz maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/AthenZ/athenz/security/advisories/new) form.

For more details, see the [Athenz security policy](https://github.com/AthenZ/athenz/blob/main/SECURITY.md).
